# Eclipser Labs

Engineering tools, infrastructure, and applied research.

We build execution layers for automated systems that do consequential work — governed runs, fallback paths, and verifiable records of what happened.

## Focus

**Safe execution for agents**
Systems for routing consequential operations through a durable boundary: `Action -> Run -> Proof`.

**Policy and control**
Policy-checked tool execution, so agents can act within explicit guardrails.

**Adaptive decision-making**
Decision and reasoning components for dynamic environments — changing arm sets, multi-objective rewards, real costs for bad draws.
